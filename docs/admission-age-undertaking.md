# Parent undertaking for age mismatch
An enquiry can still be recorded for a requested class outside the school-configured age limits. For staff-created applications only, administrators may record a signed undertaking if the exception is lawful and school-authorized. Required signer, signed date, original physical document reference, reason and confirmation; preserve the age-rule snapshot and administrator identity in the application and audit log. Invalid dates and public age rules remain blocked. Application creation is not final enrollment; admin must approve exceptional applications. Print the undertaking before creation, retain the physical signed original; no signature is fabricated or digitally captured. Application print includes recorded undertaking details. Enquiry directory uses compact responsive rows, search/class/state filters, pagination and clear class/age status. Existing records preserved. No school age policy changed.
