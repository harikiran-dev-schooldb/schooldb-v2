# School subscription modules
Super administrators can choose multiple independent module groups under School Route Access, or apply Admissions + Support demo (Admissions, Support, basic Academic Setup, User Management, profile and inbox). Save explicitly for the selected school. Existing schools retain their current routes and default landing; no tenant configuration changes in the migration. Selecting module cards opts the school into strict operational API filtering; admissions-only and admissions/support combinations also retain strict filtering without the flag. Existing legacy broad presets retain their previous policy. Unknown operational APIs using requireTenant fail closed in strict mode. Support ticket actor and unread counts check the school route; parent QR checks the strict package; mobile context filters advertised staff modules. Support student lookup is purpose-specific and returns limited student information when Support is enabled. The broader ERP module cards need endpoint coverage review, especially shared operations, and authenticated browser/native testing before commercial rollout. Public/self-service and requireMembership-only endpoints outside the checked support paths still require a comprehensive entitlement audit. No billing or subscription payment integration.
