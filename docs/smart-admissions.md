# Smart Admissions

Admissions → Smart Pipeline shows all application states, bounded previews, overdue follow-ups, and administrator-only seat counts. Open cards to use existing audited stage actions. Seat capacity is a target for new admission applications (not the total school roster). Approved applications hold one seat until returned, waitlisted, rejected or converted. Enforcement is opt-in per school/year/class; existing targets remain planning-only. At capacity an approval returns a conflict and staff can deliberately waitlist the applicant. No automatic admissions decisions. Existing document and stage approval guards are preserved. No migration or live school settings changes required. The public application academic-year policy and dedicated financial workflows remain separate work.
