# Admission smart reminders
Existing opt-in setting enables daily admin and assigned staff summaries via existing 8:15 AM IST cron. Admin counts required pending verification, drafts, and converted applications whose student has due unpaid/partial ERP installments in an enabled admissions year; it is not a pre-enrollment payment status. Staff summaries and timed alerts target only active assigned same-school staff memberships, with no student PII. Timed endpoint GET /api/cron/admissions-appointments requires CRON_SECRET as Bearer token; schedule every 5 minutes using a supported scheduler or Vercel plan supporting frequent cron. Existing Vercel daily schedule is unchanged to avoid Hobby frequency restrictions. Timed alerts use upcoming 30-minute window, deduped by application/stage/assignee/appointment date, and expire at appointment start. Delivery may be delayed by provider/queue. Daily appointment queries capped at 500 per stage per school. Parent WhatsApp buttons generate opt-in, manual drafts with appointment details; no auto sends or allowlist changes. Automatic WhatsApp appointment delivery still requires an approved template, consent lifecycle and explicit extension of existing source policy. No production messages sent or data migrations required.
