# SchoolDB feature checklist

This checklist reflects features present in the application, not deployment configuration.

## Administration and access

- [x] Multi-school tenant isolation
- [x] Role-based staff access
- [x] WhatsApp OTP sign-in
- [x] Staff account provisioning
- [x] Activity and audit logs

## Student lifecycle

- [x] Online admissions and application tracking
- [x] Student profiles, guardians, documents, and status history
- [x] Enrollment and annual promotion
- [x] ID cards and certificates
- [x] Student and guardian self-service

## Academics

- [x] Academic years, classes, sections, and subjects
- [x] Teacher allocations and timetables
- [x] Attendance marking, locking, corrections, reports, and ranking
- [x] Homework
- [x] Exams, marks, results, toppers, and report cards

## Finance

- [x] Fee plans, installments, concessions, collection, receipts, and voids
- [x] Cashfree self-service checkout, staff QR collection, verified webhooks, and automatic receipts
- [x] Outstanding-fee reporting and reminders
- [x] Expense ledger, categories, summaries, and audited voids
- [ ] Budgets and budget-versus-actual reporting
- [ ] Payroll processing and payslips

## Communication and services

- [x] Announcements, audience targeting, and in-app notices
- [x] WhatsApp campaigns, automation, retries, and delivery tracking
- [x] School calendar and leave requests
- [x] Library and transport management
- [ ] Push notifications
- [ ] Inventory and asset management

## Data and reporting

- [x] Dashboard and operational reports
- [x] CSV bulk imports and exports
- [x] System export and health status
- [ ] Configurable approval workflows
- [ ] Regulator-specific reports
- [ ] Offline-friendly attendance and homework
- [ ] Native mobile applications
