# Receptionist User Guide

The Receptionist's default access covers the dashboard, students, online admissions, student ID cards, front-office operations, and support queries. An administrator may adjust these permissions.

## Admissions and students

- Use **Online Admissions** to review and process applications.
- Verify the applicant, guardian contact, class requested, and documents before changing status.
- Convert an approved application only once and confirm the resulting student record.
- Use **Students** to find or update permitted profile information.
- Use **Student ID Cards** to filter, preview, and print approved cards.

Do not create a duplicate student because spelling differs. Search by admission number, guardian phone, and existing application first.

## Visitor desk

1. Open **Visitors & Gate Passes**.
2. Record the visitor's name, contact, purpose, person to meet, and required identification.
3. Follow the school's approval/security process before entry.
4. Record check-out when the visitor leaves.

A visitor check-in can be queued offline on a prepared device. Confirm it appears online after reconnection.

## Student pickup

1. Find the correct student.
2. Verify the authorized person's identity and relationship.
3. Record the authorization and pickup details.
4. Follow the school escalation process for any mismatch.

Pickup authorization can be saved offline when the student directory was synced. Offline capability does not replace physical identity verification.

## Health and maintenance

- Use **Student Health** only for authorized health-office records and keep details confidential.
- Use **Maintenance Tickets** to record location, issue, priority, and status.
- Use **Queries** to create or follow support requests assigned to staff.

## End-of-shift checklist

- Check out remaining visitors or hand them over clearly.
- Confirm pickup and admission changes are synchronized.
- Review unresolved maintenance tickets and queries.
- Secure printed forms and ID cards.
- Confirm **Pending requests** is zero before clearing app data or handing over the device.
