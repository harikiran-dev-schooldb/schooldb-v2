# Teacher User Guide

Teachers start on **My Dashboard**. The visible classes and modules depend on allocations, teacher feature settings, and any custom permission assigned by an administrator.

## Daily workflow

1. Open **My Dashboard** and review today's classes and work.
2. Open **Attendance → Mark Attendance**.
3. Select the correct date, class, and section; mark every student; review the counts; then save.
4. Open **Learning → Homework** to create or review assignments.
5. Use **Timetable → Daily View** or **Teacher View** for the schedule.
6. Check **Notifications**, **Queries**, and **Leave Requests**.

## Attendance

- Verify the date and class before marking.
- Do not mark a student from memory if the roster is unclear.
- Submit one complete session rather than several partial duplicates.
- Use Class Report, Student Report, and Attendance Ranking when they are enabled.
- Locked-session correction depends on school policy and administrator authority.

## Homework

1. Choose the allocated class/section and subject.
2. Enter a clear title, instructions, and due date.
3. Review the audience before publishing.
4. Edit or remove an item only according to school policy.

## Exams and marks

Open **Learning → Exams & Results**, choose the exam and schedule, and enter marks only for the assigned subject or class. Check maximum marks, absent status, and every value before saving.

## Student information

Teachers normally receive view access to the student directory. Private tabs and edit actions are restricted by role and school policy. Use student information only for teaching and safeguarding purposes.

## Good practice

- Finish attendance close to the class time.
- Use precise homework instructions and realistic due dates.
- Never share one student's marks, documents, health data, or contact details with another family.
- Report an incorrect allocation to the Principal/Admin instead of working around it.
- Confirm important changes appear in SchoolDB before leaving the page.
