# Student User Guide

The Student account opens a personal **Student space**. It only provides access to the student linked to that login.

## Use the dashboard

The dashboard shows current attendance, active homework, fee balance, next exam, and upcoming events. Open a module card for details:

- **Attendance** — daily record and attendance percentage.
- **Homework** — assignments, subjects, instructions, and due dates.
- **Timetable** — weekly class schedule.
- **Exams** — upcoming exam dates, subjects, and times.
- **Results** — published marks and performance.
- **Report card** — complete published academic summary.
- **Fees** — assigned fees, payments, installments, and outstanding balance.
- **Leave** — submit and track permitted leave/permission requests.
- **Transport** — assigned route and boarding information.
- **Library** — borrowed books and return details.
- **Documents** — secure school-issued records.

## Recommended routine

1. Check notifications and today's timetable.
2. Review homework and due dates.
3. Check exam updates when an assessment is approaching.
4. Review attendance regularly and report a suspected error through the school.
5. Download documents only when needed and keep them private.

## Profile image and settings

Use **Settings** to view account details. A student may submit a profile image, but it can require school approval before it is used. The student cannot edit official academic, attendance, fee, or identity records.

## Offline use

After the app has synced online, selected saved information remains readable without internet. A leave request may be queued for later submission. Results, balances, and notifications shown offline can be older than the school's live records; sync again after reconnecting.

## Get help

If a mark, attendance entry, timetable, fee, document, or personal detail appears incorrect, note the exact item and contact the relevant teacher or school office. Never use another student's account.
