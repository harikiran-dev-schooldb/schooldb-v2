# Getting Started with SchoolDB

This guide applies to every role.

## Sign in

1. Open your school's SchoolDB link.
2. Enter the mobile number registered by the school.
3. Request and enter the WhatsApp OTP.
4. If the number is linked to more than one person or role, choose the account you want to use.
5. SchoolDB opens the correct dashboard for that role.

Use **Switch account or role** when one verified number has multiple profiles. You do not need a second OTP while the current session is valid. Use **Change school** when the same user belongs to more than one school.

If no account appears, ask the school administrator to verify the registered mobile number and confirm that the account is active.

## Navigate the workspace

- Use the left sidebar on staff accounts. Select a section to reveal its pages.
- Use the sidebar search to find a module. On a keyboard, press `Ctrl+K` or `Command+K` to focus the search.
- On a phone, open the menu from the header.
- Parents and students use module cards in **Student space**.
- The account menu contains settings, device options, account switching, and sign out.

The pages you see depend on the school configuration, your role, and any custom permission assigned to you.

## Install the app

Open **App & notification settings** from the account area.

- On Android or desktop, use the browser's install option when offered.
- On iPhone/iPad, open SchoolDB in Safari, choose **Share**, then **Add to Home Screen**.
- Open the installed app and return to **App & notification settings** to enable notifications.
- Use **Add passkey** if the device supports a screen lock, fingerprint, or Face ID.

## Notifications

Enable notifications in **App & notification settings**. The browser or installed app may also ask for permission. If permission is blocked, allow SchoolDB in the device or browser settings and reopen the app.

The bell opens the notification inbox. WhatsApp is used only for configured operational messages such as OTPs and selected school alerts; normal announcements also appear inside SchoolDB.

## Data and security habits

- Confirm the school name and role displayed in the header before making changes.
- Search for the student by admission number where possible.
- Review class, section, academic year, amount, and date before saving.
- Download exports only to approved devices and remove them when no longer needed.
- Inactivate records or accounts when history must be retained; delete only when policy permits and the effect is understood.
- Sign out after using a shared device.

## Troubleshooting

| Problem | What to do |
|---|---|
| OTP did not arrive | Confirm the country code and registered number, wait for the resend timer, then retry. Contact the administrator if the number is wrong. |
| Wrong role opened | Use **Switch account or role** and select the intended profile. |
| A menu is missing | Ask the Principal/Admin to check school route access, your role, and your individual module permissions. |
| Data looks old | Check the internet connection, then refresh the page. |
| Notifications do not arrive | Check app notification permission, notification preferences, battery restrictions, and internet access. |
| Payment status is unclear | Do not collect twice. Check Payment History/UPI Verification or contact the Accountant. |
