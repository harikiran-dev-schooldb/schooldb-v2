# School Administration 2.0 — profile foundation
School card Settings opens the eleven-section administration workspace. School name and validated profile details persist; no existing school records are populated or altered by the additive private profile-table migration. Module access and landing route retain their existing enforcement. School-specific changes and configuration exports are audited against the target school. New schools no longer auto-provision the Play review account unless PLAY_REVIEW_SCHOOL_SLUG explicitly matches a demo/testing slug; existing memberships are unchanged.
 
Safety boundaries: proposed slug is recorded, not applied; public/native routes and aliases require a coordinated migration before a live rename. Subscription, administrative status, time zone/date format, document branding text and communication fields are descriptive, not enforcement or document-rendering changes. Logo uses existing private storage. Existing academic, admissions, communication, user and report tools are linked and retain permission checks; links need target-school membership and enabled routes. Export is configuration only, not a full tenant backup. No automatic billing, expiry-based suspension, school data deletion, or signature/seal uploads in this release. Verify CI, staging migration, and authenticated navigation before production.

Admissions event alerts and existing daily reminders have independent opt-in switches (off by default). New enquiry/application, status, stage and conversion alerts use administrator-only announcements and durable push jobs, with no personal student information. Push is attempted after the successful admission write, failures do not undo it; the existing daily cron retries queued jobs. Alert enablement does not backfill historical events.

Daily reminders also summarize unreviewed parent enquiries, applications requiring document verification, approved applications awaiting conversion, and submitted/reviewing applications unchanged for three days. Categories may overlap. Disabled admissions or notification routes suppress reminders.
